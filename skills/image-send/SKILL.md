# 成果物（画像・ファイル）をユーザーに返す方法

## 送信コマンド
curl -s -X POST "$(cat ~/.discord-webhook-url)" \
  -F "content=説明コメント（何のファイルか1行）" \
  -F "file=@/path/to/ファイル.png" -w "\nHTTP:%{http_code}"
※ 成功判定は HTTP:200。Webhook URLは ~/.discord-webhook-url に保存済み

## 使う場面
- ユーザーの説明用の図解・イラストを作ったとき
- 画像の加工・変換・リサイズ結果を返すとき
- 学習ログのまとめやプリント形式の資料を渡すとき
- 長文の回答をテキストファイルにして渡すとき

## 画像の作り方（ユーザーの理解を助ける図）
- python3 + matplotlib で図を生成できる（例: グラフ、流れ図）
- 生成したら /tmp に一旦保存し、説明コメントとセットでWebhook送信
- 図は「文字を大きく・1枚1メッセージ」を基本にする（読みやすさ優先）

## 画像の加工（リクエストされたとき）
- リサイズ/回転/形式変換: python3 + Pillow（PIL）
- 例: 指定サイズへの縮小、PNG→JPG変換、明るさ調整
- 加工前の元ファイルは消さず ~/ai-agent-files/ に残す

## 注意
- 送るファイル名はユーザーが分かる名前にする（日本語可・日付を入れると整理しやすい）
- 個人情報が写った画像は送らない
- 送信に失敗したらファイルサイズ（Discord上限約10MB）を確認して縮小して再送する
