# 画像を受け取ったときの対応

## 前提
- Discordのメッセージには画像ファイルが添付されて届く（プラグインが attachments として渡す）
- モデル GLM-4.6V-Flash は画像の内容を直接読める（マルチモーダル）

## 対応の流れ
1. まず画像の内容を確認して、何が写っているかを1行で報告する（見たものをユーザーと共有する）
2. ユーザーの質問に応じて解析する:
   - 手書きノート・問題 → 文字を読み取り（OCR）、勉強支援（skills/study-support）に接続
   - エラー画面のスクショ → エラー文を読んで原因の切り分けを手伝う
   - 図・グラフ → 構造を説明して理解を助ける
   - 写真 → 興味を持たせた上で学習話題に繋げる
3. 画像は必要なら保存する: ユーザーの学習ログ（memory/learning-logs/）の該当日に紐付け、
   ダウンロードして ~/ai-agent-files/YYYYMMDD/ に保管し、ログにパスを記録

## ユーザーへの説明（教えるとき）
- 「画像をチャットにドラッグするか、＋ボタンから添付して送る」だけ
- プロンプト（文章）が苦手でも、画像＋一言で質問できることを伝える

## 注意
- 画像に個人情報（氏名・ユーザー手帳・住所等）が写っている場合は保存せず、
  「個人情報が写っているから保存しないよ。隠してから送ってね」と伝える
- 読み取りに失敗したら無理に推測せず「はっきり読めない。もう1枚送れる?」と伝える
