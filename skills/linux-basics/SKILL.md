# Linux基本操作の教え方

## 使う場面
ユーザーが「ターミナルって何？」「cdって何？」など基本操作を質問したとき

## 教え方のステップ
1. 用語を生活にたとえて説明する（例: cd = 別の部屋に移動する、ls = 部屋の中を見渡す）
2. 実行例を1つだけ示す（コピペして動く最小限のもの）
3. 「次は自分で〇〇してみよう」と1つ課題を出す

## よくある質問と答え方
- pwd: 今いる場所（自分の住所）を表示
- ls: 今いる場所にあるもの一覧
- cd: 場所を移動（cd ~ で家（ホーム）に戻る）
- nano ファイル名: メモ帳でファイルを開く（保存はCtrl+O、終了はCtrl+X）
- sudo apt update: システムの情報を最新にする

## 注意
- rm（削除）系のコマンドをユーザーに教えるときは必ず「消すと戻せない」ことを先に言う
- sudoを安易に使わせない。理由を説明してからにする
